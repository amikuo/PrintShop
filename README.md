# PrintShop V2.3 規格管理重做版

依 Business_Rules_Final_v4.md 重做：
- 規格／常用規格兩個可收合模組
- 品項為根節點
- 材質、尺寸、常用數量、單位隸屬品項
- 後加工獨立
- `⋯` 安全管理：編輯／停用／刪除
- 已有歷史使用的規格禁止直接刪除
- 常用規格整組保存，帶入後可修改
- 交易修改不反向污染規格資料庫


## V2.6
- 報價查看頁新增修改與安全刪除。
- 已轉訂單的報價禁止直接修改／刪除。
- 首頁近期工作調整欄位順序與狀態小圓點。


## V2.7
- 報價與訂單交易編輯器一致化。
- 直接新增訂單沿用每日共用流水序號；報價轉訂單仍沿用原報價序號。
- 報價／訂單增加計稅與不計稅總計。
- 訂單新增／修改可設定進度。
- 訂單資訊頁增加沖帳與廢單。
- 智慧搜尋留至下一階段統一實作。


## V2.7.3
- 專案模式名稱改為可搜尋既有專案；關聯只使用 project_id。
- 專案頁整合所有訂單工作單位與品項，來源單號保留追查。
- 尚無正式訂單時顯示未轉單報價作暫定內容。
- 單位欄縮至原寬約 75%，品項欄加寬；品項搜尋下拉可超過輸入框寬度。


## V2.7.4
- 專案頁升級為案件工作台，可直接更新進度與沖帳。
- 顯示專案總額／已收／未收，以及每張訂單財務狀態。
- 從專案進入訂單修改後，儲存自動返回原專案。
- 專案狀態依有效訂單全部完結且全部結清自動完成。


## V2.8
- 報價／訂單右欄共用智慧搜尋基本版。
- 依目前客戶與品項自動搜尋非廢單歷史訂單。
- 支援規格／數量組合條件與基本相關性排序。
- 可將單筆歷史品項套入目前品項，仍可自由修改。
- 可用 Modal 查看完整歷史訂單，不離開目前編輯頁。


## V2.8.1
- 智慧搜尋改為品項 → 規格 → 客戶／工作單位的相關性排序。
- 客戶與規格不再硬性排除其他同品項歷史價格。
- 專案工作單位與 linked_customer_id 納入第三層加權。
- 客戶資訊與智慧搜尋改為上下排列，智慧搜尋隨頁面捲動 Sticky 於上方。


## V2.8.2
- 修正智慧搜尋 Sticky 被短父容器限制、無法跨品項區固定的問題。
- 點擊／聚焦第 2、3、4 個品項時，自動切換智慧搜尋作用品項。
- 新增品項後自動成為目前作用品項；套用只影響該列。


## V2.8.3
- 首頁近期工作上方新增智慧訂單搜尋。
- 可跨訂單號、客戶、專案、工作單位、品項與規格搜尋。
- 搜尋結果以訂單為單位去重，可預覽符合品項並直接查看訂單。


## V2.9
- 品項搜尋下拉完整關閉規則與加寬。
- 智慧搜尋固定高度與內部捲動。
- 專案全數廢單自動已取消；有效訂單全完結自動已完成。
- 移除新增空專案入口，新增獨立的專案進度與整案沖帳。


## V2.9.1
- 交易編輯器智慧搜尋固定高度提高為 V2.9 的 1.5 倍。
- 修正品項搜尋下拉關閉後殘留白色框。
- 專案詳細頁將「專案目前內容」移至「專案批次管理／訂單控制」上方。


## V2.9.2
- 修正 V2.9 品項建議關閉後殘留空白框。
- 修正 V2.9.1 因過度隱藏品項建議容器，導致重新輸入品項時看不到基礎規格與常用規格。
- 品項建議恢復正常顯示；關閉狀態僅以 hidden / 空內容控制，不再強制寫入 inline display:none。


## V2.9.3
- 修正品項搜尋下拉因 close 時留下 hidden=true，導致再次輸入後雖已取得基礎規格／常用規格資料但仍無法顯示。
- 品項下拉改為只使用 show class 控制開關，避免 hidden 與 CSS display 狀態互相衝突。
- 關閉時同步清空結果，因此不會留下白色殘餘框；重新輸入時可正常再次開啟。
